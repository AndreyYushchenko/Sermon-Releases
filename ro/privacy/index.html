Politica de confidențialitate

Sermon este o aplicație gratuită de prezentare pentru biserici, realizată de echipa Sermon. Această pagină explică ce se întâmplă cu informațiile dvs. când folosiți aplicația Sermon și acest site.

Ultima actualizare: 11 octombrie 2026

Pe scurt

  • Sermon nu are conturi, reclame, analiză sau urmărire.
  • Cântările, textele Bibliei, anunțurile, fotografiile, videoclipurile și setările dvs. rămân pe computerul dvs.
  • Nu colectăm, nu vindem și nu partajăm date personale.
  • Aplicația se conectează la internet doar pentru funcțiile de mai jos și doar la serviciile numite acolo.

Datele de pe computerul dvs.

Biblioteca, listele de redare, cronometrele și setările dvs. sunt păstrate în dosarul de date Sermon de pe computerul dvs. Inclusiv adresa și parola serverului OBS, dacă le introduceți. Nimic din acestea nu ne este trimis.

Copiile de rezervă se salvează în dosarul ales în Setări → Backup → Dosarul de backup. Dacă acesta este un stick USB sau un dosar din cloud, cum ar fi Google Drive sau OneDrive, copiile sunt gestionate de acel suport sau serviciu.

La dezinstalarea Sermon dosarul de date rămâne, așa că după o reinstalare biblioteca revine. Puteți șterge oricând dosarul singur.

Când aplicația se conectează la internet

Actualizări. La fiecare pornire, Sermon întreabă GitHub dacă există o versiune mai nouă și descarcă programul de instalare de pe GitHub când alegeți să actualizați. GitHub vede adresa dvs. IP, așa cum se descrie în Declarația de confidențialitate GitHub. Puteți opri verificarea din Setări → General → Actualizări → Caută automat actualizări.

Fotografii și videoclipuri de pe internet. Când folosiți Caută pe internet, cuvintele căutate sunt trimise către Pexels, iar fotografiile sau videoclipurile alese sunt descărcate de pe Pexels. Vedeți Politica de confidențialitate Pexels.

YouTube. Când adăugați un link YouTube, Sermon descarcă o singură dată utilitarul gratuit yt-dlp de pe GitHub și redă videoclipul de pe YouTube. În OBS videoclipul este încorporat de pe youtube.com. YouTube este un serviciu Google: vedeți Politica de confidențialitate Google.

Nu se trimite nimic altceva: nicio statistică de utilizare, niciun raport de eroare și nicio dată personală.

În rețeaua dvs. locală

Diapozitive pentru OBS. Sermon afișează diapozitivul curent ca pagină web în rețeaua dvs. (portul 8090), ca OBS sau un browser de pe alt computer să îl poată arăta. Oricine din aceeași rețea poate deschide această pagină. Ea arată doar ce este pe proiector. La prima pornire, Windows poate întreba dacă permiteți acest lucru.

Integrarea OBS funcționează doar când activați Activează integrarea OBS. Atunci Sermon se conectează la OBS cu parola introdusă, schimbă scenele și ține la zi adresa din sursele Browser. Dacă OBS nu răspunde la adresa salvată, Sermon îl caută în rețeaua dvs. locală, verificând ce computere răspund pe portul OBS. Totul rămâne în rețeaua dvs.

Acest site

Site-ul este găzduit pe GitHub Pages. GitHub poate înregistra adresele IP ale vizitatorilor din motive de securitate, așa cum se descrie în Declarația de confidențialitate GitHub.

Nu există cookie-uri, analiză sau reclame. Fonturile sunt încărcate de pe acest site, nu de la Google. Browserul dvs. reține limba aleasă și tema deschisă sau închisă (stocare locală); aceste date nu părăsesc niciodată browserul.

Butoanele de descărcare întreabă GitHub de cea mai nouă versiune, așa că browserul dvs. contactează api.github.com.

Dacă ne scrieți

Când scrieți la sermon.support@gmail.com, primim adresa și mesajul dvs. și le folosim doar pentru a vă răspunde. Căsuța de e-mail este administrată de Gmail (Politica de confidențialitate Google). La cerere, vă ștergem e-mailurile.

Drepturile dvs.

Nu păstrăm date personale despre utilizatorii Sermon, așa că nu avem ce să vă arătăm, să corectăm sau să ștergem. Pentru e-mailurile trimise nouă, scrieți la sermon.support@gmail.com. Dacă locuiți în UE sau Regatul Unit, aveți și drepturile oferite de GDPR, inclusiv dreptul de a depune o plângere la autoritatea de protecție a datelor.

Sermon nu se adresează copiilor și nu colectează intenționat datele nimănui.

Modificări și contact

Dacă această politică se schimbă, actualizăm această pagină și data ei. Modificările importante sunt menționate și în notele versiunii.

Echipa Sermon — sermon.support@gmail.com

Nu aveți încă Sermon?

Gratuit, funcționează offline, fără înregistrare.
