Política de privacidade

O Sermon é um aplicativo gratuito de apresentação para igrejas, feito pela equipe Sermon. Esta página explica o que acontece com suas informações quando você usa o aplicativo Sermon e este site.

Última atualização: 11 de outubro de 2026

Resumo

  • O Sermon não tem contas, anúncios, análises nem rastreamento.
  • Suas músicas, textos bíblicos, avisos, fotos, vídeos e configurações ficam no seu computador.
  • Não coletamos, vendemos nem compartilhamos dados pessoais.
  • O aplicativo se conecta à internet só para os recursos descritos abaixo e só com os serviços citados ali.

Dados no seu computador

Sua biblioteca, listas, cronômetros e configurações ficam guardados na pasta de dados do Sermon no seu computador. Isso inclui o endereço e a senha do servidor do OBS, se você os informar. Nada disso é enviado para nós.

Os backups são salvos na pasta que você escolher em Configurações → Backup → Pasta de backups. Se essa pasta for um pen drive ou uma pasta na nuvem, como Google Drive ou OneDrive, as cópias ficam a cargo desse dispositivo ou serviço.

Ao desinstalar o Sermon, a pasta de dados permanece, então a biblioteca volta depois de uma nova instalação. Você pode apagar a pasta quando quiser.

Quando o aplicativo se conecta à internet

Atualizações. A cada início, o Sermon pergunta ao GitHub se há uma versão mais nova e baixa o instalador do GitHub quando você decide atualizar. O GitHub vê seu endereço IP, como descrito na Declaração de Privacidade do GitHub. Você pode desativar a verificação em Configurações → Geral → Atualizações → Verificar atualizações automaticamente.

Fotos e vídeos da internet. Quando você usa Buscar na internet, as palavras pesquisadas são enviadas ao Pexels, e as fotos ou vídeos escolhidos são baixados do Pexels. Veja a Política de Privacidade do Pexels.

YouTube. Quando você adiciona um link do YouTube, o Sermon baixa uma vez a ferramenta gratuita yt-dlp do GitHub e reproduz o vídeo a partir do YouTube. No OBS, o vídeo é incorporado a partir de youtube.com. O YouTube é um serviço do Google: veja a Política de Privacidade do Google.

Nada mais é enviado: nenhuma estatística de uso, nenhum relatório de erros e nenhum dado pessoal.

Na sua rede local

Slides para o OBS. O Sermon mostra o slide atual como uma página web na sua rede (porta 8090), para que o OBS ou um navegador em outro computador possa exibi-lo. Qualquer pessoa na mesma rede pode abrir essa página. Ela mostra apenas o que está no projetor. Na primeira vez, o Windows pode perguntar se você permite isso.

A integração com o OBS só funciona quando você liga Ativar a integração com o OBS. Então o Sermon se conecta ao OBS com a senha que você informou, troca as cenas e mantém atualizado o endereço nas suas fontes de navegador. Se o OBS não responder no endereço salvo, o Sermon o procura na sua rede local, verificando quais computadores respondem na porta do OBS. Tudo isso fica dentro da sua rede.

Este site

O site é hospedado no GitHub Pages. O GitHub pode registrar os endereços IP dos visitantes por segurança, como descrito na Declaração de Privacidade do GitHub.

Não há cookies, análises nem anúncios. As fontes são carregadas deste site, não do Google. Seu navegador lembra o idioma e o tema claro ou escuro que você escolher (armazenamento local); esses dados nunca saem do seu navegador.

Os botões de download pedem ao GitHub a versão mais recente, então seu navegador acessa api.github.com.

Se você nos escrever

Quando você escreve para sermon.support@gmail.com, recebemos seu endereço e sua mensagem e os usamos só para responder. A caixa de e-mail é do Gmail (Política de Privacidade do Google). Se pedir, apagamos seus e-mails.

Seus direitos

Não guardamos dados pessoais dos usuários do Sermon, então não temos nada para mostrar, corrigir ou apagar. Sobre os e-mails que você nos enviou, escreva para sermon.support@gmail.com. Se você mora na UE ou no Reino Unido, também tem os direitos do GDPR, incluindo o direito de reclamar à autoridade de proteção de dados. No Brasil, você tem os direitos previstos na LGPD.

O Sermon não se destina a crianças e não coleta conscientemente dados de ninguém.

Alterações e contato

Se esta política mudar, atualizaremos esta página e a data. Mudanças importantes também são mencionadas nas notas da versão.

Equipe Sermon — sermon.support@gmail.com
