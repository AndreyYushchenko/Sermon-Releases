Show Sermon slides in OBS

Put the songs, Bible verses and announcements from your projector into the livestream. Sermon gives OBS a web page with the current slide: add it once as a Browser source, and from then on it follows the projector.

  • About 5 minutes
  • OBS Studio 28 or newer
  • This computer or another one on your network

Before you start

  • Sermon 0.3.0 or newer. Connected to OBS, it keeps the address in OBS up to date by itself, even when the router gives a computer a new IP address.
  • OBS Studio installed — on this computer or on another computer on the same network.
  • Sermon open during the service: OBS takes the slides from it.

Connect in 5 steps

1

Step 1

Copy the address in Sermon

In the right panel, next to OBS, click Address 1. The link is copied to the clipboard. It looks like http://192.168.1.25:8090/display.

The same link is in Settings → OBS and network → Address for the Browser source. It contains this computer’s IP address. If OBS runs on another computer, also connect Sermon to OBS: then, when the router gives a computer a new IP address, Sermon rewrites the address in OBS by itself, and you never paste it again.

2

Step 2

Add a source in OBS

Open OBS Studio and select the scene the slides should appear in — for example, the scene with your camera. Under Sources, click + 1.

3

Step 3

Choose “Browser”

In the Add Source window, select Browser 1 and click Add a new Browser 2.

4

Step 4

Paste the address and set the size

URL 1: clear the field and paste the address (Ctrl+V).
Width 2: 1920, Height 3: 1080.

Leave everything else as it is and click OK 4.

The preview at the top of this window updates only after you click OK. When you open the properties again later, you’ll see the slide there, as in the picture.

5

Step 5

Check the result

The current slide now appears in OBS and changes together with the projector. OBS remembers the source — you only do this once.

If the slide doesn’t fill the frame, right-click the source and choose Transform → Fit to screen (Ctrl+F).

Tip. To let your camera show through when nothing is on screen, set Settings → Display → Between services → Nothing in Sermon: OBS then gets a transparent page. To hide the slides from the stream only, click Hide next to OBS in Sermon — the projector keeps showing.

Connect Sermon to OBS

Recommended when OBS runs on another computer. Once connected, Sermon updates the address in the Browser source by itself when the router gives a computer a new IP address, and finds OBS on the network if OBS’s own address changed. It can also switch OBS to a chosen scene when something goes on screen, and back when you hide it. This uses the WebSocket server built into OBS.

A

Open the WebSocket settings

In OBS, open Tools 1 → WebSocket Server Settings 2.

B

Turn on the server

Tick Enable WebSocket server 1. Type your own password in Server Password 2 or keep the generated one. Click OK 3.

C

Find the server address and password

Open Tools → WebSocket Server Settings again and click Show Connect Info. This window has everything Sermon needs: Server IP 1 — the address of the computer OBS runs on, Server Port 2 and Server Password 3. Each has a Copy button.

If OBS and Sermon run on the same computer, Sermon can keep the address localhost. The Server IP is needed when OBS is on another computer.

D

Connect Sermon

In Sermon, open Settings → OBS and network and turn on Enable OBS integration 1.

Server address 2: paste the Server IP from the previous step, or leave localhost if OBS is on this computer. Port: 4455. Password 3: paste the Server Password.

Click Test connection 4 — it should say Connected. To switch scenes, choose one in Show scene. Click Save.

If something doesn’t work

OBS shows an empty or white frame
  • Check that Sermon is open and the status next to OBS in its right panel says Running.
  • Copy the address again with the Address button and paste it into the source’s URL field.
  • Click Refresh under the OBS preview.
OBS runs on a different computer
  • Both computers must be on the same network (the same router or Wi-Fi).
  • When Sermon starts for the first time, Windows may ask whether it can use the network. Click Allow. If you closed that window, allow Sermon in the Windows Firewall settings.
  • When the router gives a computer a new IP address, Sermon connected to OBS fixes the address in OBS by itself within a minute. Without the connection, copy the address in Sermon again and paste it into the source.
  • For an address that never changes at all, reserve a fixed IP address for the Sermon computer in your router’s settings (often called DHCP reservation).
The address stopped working
  • The router gave the computer a new IP address. Connect Sermon to OBS, and from then on Sermon fixes the address by itself. Until then, copy the address again.
  • If the address ends in :8091 or higher, port 8090 was busy — for example, a second copy of Sermon was open. Close all copies and start Sermon again.
The slide is small or cut off

In the source properties set Width to 1920 and Height to 1080. Then right-click the source → Transform → Fit to screen.

Sermon doesn’t connect to OBS
  • Check that Enable WebSocket server is ticked in OBS and the password in Sermon is exactly the same.
  • The port must be 4455 in both programs.
  • If OBS is on another computer, Server address must be the Server IP from Show Connect Info, not localhost. Allow OBS in that computer’s firewall.
