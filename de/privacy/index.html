Datenschutzerklärung

Sermon ist eine kostenlose Präsentations-App für Gemeinden, entwickelt vom Sermon-Team. Diese Seite erklärt, was mit Ihren Informationen geschieht, wenn Sie die Sermon-App und diese Website nutzen.

Zuletzt aktualisiert: 11. Oktober 2026

Auf dieser Seite

Kurz gesagt Daten auf Ihrem Computer Wann die App online geht In Ihrem lokalen Netzwerk Diese Website Wenn Sie uns schreiben Ihre Rechte Änderungen und Kontakt

Kurz gesagt

  • Sermon hat keine Konten, keine Werbung, keine Analyse und kein Tracking.
  • Ihre Lieder, Bibeltexte, Ankündigungen, Fotos, Videos und Einstellungen bleiben auf Ihrem Computer.
  • Wir erheben, verkaufen und teilen keine personenbezogenen Daten.
  • Die App geht nur für die unten genannten Funktionen online, und nur zu den dort genannten Diensten.

Daten auf Ihrem Computer

Ihre Bibliothek, Wiedergabelisten, Timer und Einstellungen werden im Datenordner von Sermon auf Ihrem Computer gespeichert. Dazu gehören auch Adresse und Passwort des OBS-Servers, wenn Sie sie eingeben. Nichts davon wird an uns gesendet.

Sicherungen werden in dem Ordner gespeichert, den Sie unter Einstellungen → Sicherung → Sicherungsordner wählen. Ist das ein USB-Stick oder ein Cloud-Ordner wie Google Drive oder OneDrive, liegen die Kopien bei diesem Laufwerk oder Dienst.

Beim Deinstallieren von Sermon bleibt der Datenordner erhalten, sodass Ihre Bibliothek nach einer Neuinstallation wieder da ist. Sie können den Ordner jederzeit selbst löschen.

Wann die App online geht

Updates. Bei jedem Start fragt Sermon bei GitHub nach, ob es eine neuere Version gibt, und lädt das Installationsprogramm von GitHub herunter, wenn Sie aktualisieren möchten. GitHub sieht dabei Ihre IP-Adresse, wie in der GitHub-Datenschutzerklärung beschrieben. Sie können die Prüfung unter Einstellungen → Allgemein → Updates → Automatisch nach Updates suchen ausschalten.

Fotos und Videos aus dem Internet. Wenn Sie Im Internet suchen verwenden, werden Ihre Suchbegriffe an Pexels gesendet, und die ausgewählten Bilder oder Videos werden von Pexels heruntergeladen. Siehe die Datenschutzerklärung von Pexels.

YouTube. Wenn Sie einen YouTube-Link hinzufügen, lädt Sermon einmalig das kostenlose Werkzeug yt-dlp von GitHub herunter und spielt das Video von YouTube ab. In OBS wird das Video von youtube.com eingebettet. YouTube ist ein Dienst von Google: siehe die Datenschutzerklärung von Google.

Sonst wird nichts gesendet: keine Nutzungsstatistik, keine Absturzberichte und keine personenbezogenen Daten.

In Ihrem lokalen Netzwerk

Folien für OBS. Sermon stellt die aktuelle Folie als Webseite in Ihrem Netzwerk bereit (Port 8090), damit OBS oder ein Browser auf einem anderen Computer sie anzeigen kann. Jeder im selben Netzwerk kann diese Seite öffnen. Sie zeigt nur, was gerade auf dem Projektor ist. Beim ersten Start fragt Windows eventuell, ob das erlaubt werden soll.

Die OBS-Integration arbeitet nur, wenn Sie OBS-Integration aktivieren einschalten. Dann verbindet sich Sermon mit dem eingegebenen Passwort mit OBS, wechselt Szenen und hält die Adresse in Ihren Browser-Quellen aktuell. Ist OBS unter der gespeicherten Adresse nicht erreichbar, sucht Sermon OBS in Ihrem lokalen Netzwerk, indem es prüft, welche Computer auf dem OBS-Port antworten. All das bleibt innerhalb Ihres Netzwerks.

Diese Website

Die Website wird auf GitHub Pages bereitgestellt. GitHub kann die IP-Adressen der Besucher aus Sicherheitsgründen protokollieren, wie in der GitHub-Datenschutzerklärung beschrieben.

Es gibt keine Cookies, keine Analyse und keine Werbung. Die Schriften werden von dieser Website geladen, nicht von Google. Ihr Browser merkt sich die gewählte Sprache und das helle oder dunkle Design (lokaler Speicher); diese Daten verlassen Ihren Browser nie.

Die Download-Schaltflächen fragen bei GitHub nach der neuesten Version, daher kontaktiert Ihr Browser api.github.com.

Wenn Sie uns schreiben

Wenn Sie an sermon.support@gmail.com schreiben, erhalten wir Ihre Adresse und Ihre Nachricht und verwenden sie nur, um Ihnen zu antworten. Das Postfach wird von Gmail betrieben (Datenschutzerklärung von Google). Auf Wunsch löschen wir Ihre E-Mails.

Ihre Rechte

Wir speichern keine personenbezogenen Daten über Sermon-Nutzer, daher gibt es nichts, was wir anzeigen, berichtigen oder löschen könnten. Zu E-Mails, die Sie uns geschickt haben, schreiben Sie an sermon.support@gmail.com. Wenn Sie in der EU oder im Vereinigten Königreich leben, haben Sie außerdem die Rechte aus der DSGVO, einschließlich des Rechts auf Beschwerde bei Ihrer Datenschutzbehörde.

Sermon richtet sich nicht an Kinder und erhebt wissentlich von niemandem Daten.

Änderungen und Kontakt

Ändert sich diese Erklärung, aktualisieren wir diese Seite und ihr Datum. Wichtige Änderungen werden auch in den Versionshinweisen erwähnt.
