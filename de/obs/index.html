Sermon-Folien in OBS

Bringen Sie Lieder, Bibelverse und Ankündigungen vom Beamer in Ihren Livestream. Sermon gibt OBS eine Webseite mit der aktuellen Folie: Fügen Sie sie einmal als Browser-Quelle hinzu, danach folgt sie dem Beamer.

  • Etwa 5 Minuten
  • OBS Studio 28 oder neuer
  • Dieser Computer oder ein anderer im Netzwerk

Bevor Sie beginnen

  • Sermon 0.3.0 oder neuer. Mit OBS verbunden, hält es die Adresse in OBS selbst aktuell, auch wenn der Router einem Computer eine neue IP-Adresse gibt.
  • OBS Studio ist installiert, auf diesem Computer oder auf einem anderen im selben Netzwerk.
  • Sermon ist während des Gottesdienstes geöffnet: OBS holt die Folien von dort.

In 5 Schritten verbinden

1

Schritt 1

Adresse in Sermon kopieren

Klicken Sie im rechten Bereich neben OBS auf Adresse 1. Der Link wird in die Zwischenablage kopiert. Er sieht so aus: http://192.168.1.25:8090/display.

Denselben Link finden Sie unter Einstellungen → OBS und Übertragung → Adresse für die Browserquelle. Er enthält die IP-Adresse dieses Computers. Läuft OBS auf einem anderen Computer, verbinden Sie Sermon auch mit OBS: Gibt der Router einem Computer eine neue IP-Adresse, schreibt Sermon die Adresse in OBS dann selbst neu, und Sie müssen sie nie wieder einfügen.

2

Schritt 2

Quelle in OBS hinzufügen

Öffnen Sie OBS Studio und wählen Sie die Szene, in der die Folien erscheinen sollen, zum Beispiel die Szene mit Ihrer Kamera. Klicken Sie unter Quellen auf + 1.

3

Schritt 3

„Browser“ wählen

Wählen Sie im Fenster zum Hinzufügen einer Quelle Browser 1 und legen Sie eine neue Quelle an 2.

4

Schritt 4

Adresse einfügen und Größe festlegen

URL 1: Feld leeren und die Adresse einfügen (Strg+V).
Breite 2: 1920, Höhe 3: 1080.

Alles andere so lassen und auf OK 4 klicken.

Die Vorschau oben in diesem Fenster aktualisiert sich erst nach OK. Wenn Sie die Eigenschaften später wieder öffnen, sehen Sie dort die Folie wie im Bild.

5

Schritt 5

Ergebnis prüfen

Die aktuelle Folie erscheint jetzt in OBS und wechselt zusammen mit dem Beamer. OBS merkt sich die Quelle: Das machen Sie nur einmal.

Füllt die Folie das Bild nicht aus, klicken Sie mit der rechten Maustaste auf die Quelle und wählen Transformieren → An Bildschirm anpassen (Strg+F).

Tipp. Damit Ihre Kamera durchscheint, wenn nichts gezeigt wird, stellen Sie in Sermon Einstellungen → Bildschirm und Anzeige → Zwischen Gottesdiensten → Nichts ein: OBS bekommt dann eine transparente Seite. Um die Folien nur im Stream auszublenden, klicken Sie in Sermon neben OBS auf Ausblenden: Der Beamer zeigt weiter.

Sermon mit OBS verbinden

Empfohlen, wenn OBS auf einem anderen Computer läuft. Einmal verbunden, aktualisiert Sermon die Adresse in der Browserquelle selbst, wenn der Router einem Computer eine neue IP-Adresse gibt, und findet OBS im Netzwerk, wenn sich die Adresse von OBS geändert hat. Außerdem kann es OBS auf eine gewählte Szene umschalten, sobald etwas gezeigt wird, und zurück, wenn Sie es ausblenden. Dafür wird der in OBS eingebaute WebSocket-Server genutzt.

A

WebSocket-Einstellungen öffnen

Öffnen Sie in OBS Werkzeuge 1 → WebSocket-Servereinstellungen 2.

B

Server einschalten

Setzen Sie das Häkchen bei WebSocket-Server aktivieren 1. Geben Sie ein eigenes Passwort unter Serverpasswort 2 ein oder behalten Sie das erzeugte. Klicken Sie auf OK 3.

C

Serveradresse und Passwort finden

Öffnen Sie Werkzeuge → WebSocket-Servereinstellungen erneut und klicken Sie auf Verbindungsinformationen anzeigen. Dieses Fenster enthält alles, was Sermon braucht: die Server-IP 1, also die Adresse des Computers mit OBS, den Serverport 2 und das Serverpasswort 3. Jedes Feld hat eine Schaltfläche zum Kopieren.

Laufen OBS und Sermon auf demselben Computer, kann Sermon die Adresse localhost behalten. Die Server-IP brauchen Sie, wenn OBS auf einem anderen Computer läuft.

D

Sermon verbinden

Öffnen Sie in Sermon Einstellungen → OBS und Übertragung und schalten Sie OBS-Integration aktivieren 1 ein.

Serveradresse 2: die Server-IP aus dem vorigen Schritt einfügen, oder localhost lassen, wenn OBS auf diesem Computer läuft. Port: 4455. Passwort 3: das Serverpasswort einfügen.

Klicken Sie auf Verbindung testen 4: Es sollte Verbunden erscheinen. Für den Szenenwechsel wählen Sie eine Szene unter Präsentationsszene. Klicken Sie auf Speichern.

Wenn etwas nicht klappt

OBS zeigt ein leeres oder weißes Bild
  • Prüfen Sie, ob Sermon geöffnet ist und neben OBS im rechten Bereich Läuft steht.
  • Kopieren Sie die Adresse erneut mit der Schaltfläche Adresse und fügen Sie sie in das Feld URL der Quelle ein.
  • Klicken Sie unter der OBS-Vorschau auf Aktualisieren.
OBS läuft auf einem anderen Computer
  • Beide Computer müssen im selben Netzwerk sein (derselbe Router oder dasselbe WLAN).
  • Beim ersten Start von Sermon fragt Windows eventuell, ob es das Netzwerk nutzen darf. Klicken Sie auf Zulassen. Haben Sie das Fenster geschlossen, erlauben Sie Sermon in den Einstellungen der Windows-Firewall.
  • Gibt der Router einem Computer eine neue IP-Adresse, korrigiert ein mit OBS verbundenes Sermon die Adresse in OBS innerhalb einer Minute selbst. Ohne Verbindung kopieren Sie die Adresse in Sermon erneut und fügen sie in die Quelle ein.
  • Für eine Adresse, die sich nie ändert, reservieren Sie in den Router-Einstellungen eine feste IP-Adresse für den Sermon-Computer (oft DHCP-Reservierung genannt).
Die Adresse funktioniert nicht mehr
  • Der Router hat dem Computer eine neue IP-Adresse gegeben. Verbinden Sie Sermon mit OBS, dann korrigiert Sermon die Adresse künftig selbst. Bis dahin kopieren Sie die Adresse erneut.
  • Endet die Adresse auf :8091 oder höher, war Port 8090 belegt, zum Beispiel durch eine zweite geöffnete Sermon-Kopie. Schließen Sie alle Kopien und starten Sie Sermon neu.
Die Folie ist klein oder abgeschnitten

Stellen Sie in den Eigenschaften der Quelle Breite auf 1920 und Höhe auf 1080. Dann Rechtsklick auf die Quelle → Transformieren → An Bildschirm anpassen.

Sermon verbindet sich nicht mit OBS
  • Prüfen Sie, ob in OBS WebSocket-Server aktivieren angehakt ist und das Passwort in Sermon genau gleich ist.
  • Der Port muss in beiden Programmen 4455 sein.
  • Läuft OBS auf einem anderen Computer, muss die Serveradresse die Server-IP aus den Verbindungsinformationen sein, nicht localhost. Erlauben Sie OBS in der Firewall dieses Computers.
