So importieren Sie in Sermon

Liederbuch importieren

  1. Laden Sie die Liederbuch-Datei herunter (Format .sps).
  2. Öffnen Sie in Sermon Einstellungen → Daten und Sicherungen und klicken Sie unter „Liederbücher“ auf .sps laden…
  3. Wählen Sie die Datei: Die Lieder erscheinen in der Bibliothek als eigenes Liederbuch.

Bibelübersetzung importieren

  1. Laden Sie die Bibel-Datei herunter (.spb).
  2. Klicken Sie auf derselben Seite unter „Bibelübersetzungen“ auf Übersetzung laden…
  3. Wählen Sie die Datei: Die Übersetzung steht sofort zur Auswahl.

Sie haben ein Liederbuch oder eine Bibelübersetzung?

Schicken Sie es uns, und wir nehmen es für alle Gemeinden in die Bibliothek auf. Eine Datei aus einem anderen Programm, ein Dokument oder eine Liederliste: Um das Format kümmern wir uns.
