How to Import Content into Sermon

Importing Songbooks

  1. Download the songbook file (.sps format).
  2. In Sermon, open Settings → Database and click Load .sps… under “Songbooks”.
  3. Pick the file — its songs appear in your library as a separate songbook.

Importing Bible Translations

  1. Download the Bible file (.spb).
  2. On the same Settings → Database page, click Load translation… under “Bible translations”.
  3. Select the file — the translation will immediately appear in your picker for live projection.
