Sermon으로 가져오는 방법

찬양집 가져오기

  1. 찬양집 파일(.sps 형식)을 내려받습니다.
  2. Sermon에서 설정 → 데이터 및 백업을 열고 ‘찬양집’에서 .sps 불러오기…를 누릅니다.
  3. 파일을 선택하면 찬양이 라이브러리에 별도의 찬양집으로 나타납니다.

성경 번역본 가져오기

  1. 성경 파일(.spb)을 내려받습니다.
  2. 같은 페이지의 ‘성경 번역본’에서 번역본 불러오기…를 누릅니다.
  3. 파일을 선택하면 번역본이 바로 목록에 나타납니다.

찬양집이나 성경 번역본이 있나요?

보내 주시면 모든 교회가 쓸 수 있도록 자료실에 추가하겠습니다. 다른 프로그램의 파일, 문서, 찬양 목록 무엇이든 괜찮습니다. 형식은 저희가 맞추겠습니다.
