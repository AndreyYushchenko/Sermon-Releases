OBS에서 Sermon 슬라이드

프로젝터에 띄운 찬양, 성경 구절, 광고를 방송에도 보내세요. Sermon은 OBS에 현재 슬라이드가 담긴 웹 페이지를 제공합니다. 브라우저 소스로 한 번만 추가하면 그다음부터는 프로젝터를 그대로 따라갑니다.

  • 약 5분
  • OBS Studio 28 이상
  • 이 컴퓨터 또는 같은 네트워크의 다른 컴퓨터

이 페이지의 내용

시작하기 전에 1Sermon에서 주소 복사 2OBS에 소스 추가 3‘브라우저’ 선택 4주소 붙여 넣고 크기 설정 5결과 확인 Sermon을 OBS에 연결하기 잘 안 될 때

시작하기 전에

  • Sermon 0.3.0 이상. OBS와 연결하면 공유기가 컴퓨터에 새 IP 주소를 주더라도 OBS의 주소를 스스로 최신으로 유지합니다.
  • OBS Studio이(가) 이 컴퓨터나 같은 네트워크의 다른 컴퓨터에 설치되어 있어야 합니다.
  • 예배 중에는 Sermon이 열려 있어야 합니다. OBS가 여기서 슬라이드를 가져옵니다.

5단계로 연결하기

1

단계 1

Sermon에서 주소 복사

오른쪽 패널의 OBS 옆에서 주소 1를 누르세요. 링크가 클립보드에 복사됩니다. http://192.168.1.25:8090/display와 비슷한 모양입니다.

같은 링크는 설정 → OBS 및 방송 → 브라우저 소스용 주소에도 있습니다. 이 컴퓨터의 IP 주소가 들어 있습니다. OBS가 다른 컴퓨터에서 실행된다면 Sermon을 OBS에 연결해 두세요. 공유기가 컴퓨터의 IP를 바꿔도 Sermon이 OBS의 주소를 스스로 고쳐서 다시 붙여 넣을 필요가 없습니다.

2

단계 2

OBS에 소스 추가

OBS Studio를 열고 슬라이드가 나올 장면을 선택하세요. 예를 들어 카메라가 있는 장면입니다. 소스 목록 아래에서 + 1를 누르세요.

3

단계 3

‘브라우저’ 선택

소스 추가 창에서 브라우저 1를 고르고 새 소스를 만드세요 2.

4

단계 4

주소 붙여 넣고 크기 설정

URL 1: 칸을 비우고 주소를 붙여 넣으세요(Ctrl+V).
너비 2: 1920, 높이 3: 1080.

나머지는 그대로 두고 확인 4을 누르세요.

이 창 위쪽의 미리 보기는 확인을 누른 뒤에야 바뀝니다. 나중에 속성을 다시 열면 그림처럼 슬라이드가 보입니다.

5

단계 5

결과 확인

이제 현재 슬라이드가 OBS에 나타나고 프로젝터와 함께 바뀝니다. OBS가 소스를 기억하므로 한 번만 하면 됩니다.

슬라이드가 화면을 꽉 채우지 않으면 소스를 오른쪽 클릭하고 변환 → 화면에 맞추기(Ctrl+F)를 고르세요.

팁. 화면에 아무것도 없을 때 카메라가 보이게 하려면 Sermon에서 설정 → 화면 및 송출 → 예배 사이 → 없음을 고르세요. 그러면 OBS는 투명한 페이지를 받습니다. 방송에서만 슬라이드를 숨기려면 Sermon에서 OBS 옆의 숨기기를 누르세요. 프로젝터는 계속 보여 줍니다.

Sermon을 OBS에 연결하기

OBS가 다른 컴퓨터에서 실행될 때 권장합니다. 연결해 두면 공유기가 컴퓨터에 새 IP를 줄 때 Sermon이 브라우저 소스의 주소를 스스로 고치고, OBS의 주소가 바뀌면 네트워크에서 OBS를 다시 찾습니다. 무언가를 화면에 띄우면 OBS를 고른 장면으로 바꾸고, 숨기면 되돌릴 수도 있습니다. OBS에 들어 있는 WebSocket 서버를 사용합니다.

A

WebSocket 설정 열기

OBS에서 도구 1 → WebSocket 서버 설정 2을 여세요.

B

서버 켜기

WebSocket 서버 사용 1을 체크하세요. 서버 비밀번호 2에 직접 비밀번호를 입력하거나 만들어진 것을 그대로 두세요. 확인 3을 누르세요.

C

서버 주소와 비밀번호 찾기

도구 → WebSocket 서버 설정을 다시 열고 연결 정보 표시를 누르세요. 이 창에 Sermon에 필요한 것이 모두 있습니다. OBS가 실행되는 컴퓨터의 주소인 서버 IP 1, 서버 포트 2, 서버 비밀번호 3. 각각 복사 버튼이 있습니다.

OBS와 Sermon이 같은 컴퓨터에서 실행되면 Sermon은 localhost 주소를 그대로 써도 됩니다. 서버 IP는 OBS가 다른 컴퓨터에 있을 때 필요합니다.

D

Sermon 연결

Sermon에서 설정 → OBS 및 방송을 열고 OBS 연동 사용 1을 켜세요.

서버 주소 2: 앞 단계의 서버 IP를 붙여 넣거나, OBS가 이 컴퓨터에 있으면 localhost를 그대로 두세요. 포트: 4455. 비밀번호 3: 서버 비밀번호를 붙여 넣으세요.

연결 테스트 4를 누르면 연결됨이 나와야 합니다. 장면을 바꾸려면 송출 장면에서 하나를 고르세요. 저장을 누르세요.

잘 안 될 때

OBS에 빈 화면이나 흰 화면이 보입니다
  • Sermon이 열려 있고 오른쪽 패널의 OBS 옆 상태가 실행 중인지 확인하세요.
  • 주소 버튼으로 주소를 다시 복사해 소스의 URL 칸에 붙여 넣으세요.
  • OBS 미리 보기 아래의 새로 고침을 누르세요.
OBS가 다른 컴퓨터에서 실행됩니다
  • 두 컴퓨터가 같은 네트워크(같은 공유기나 같은 Wi-Fi)에 있어야 합니다.
  • Sermon을 처음 실행하면 Windows가 네트워크 사용을 허용할지 물을 수 있습니다. 허용을 누르세요. 창을 닫았다면 Windows 방화벽 설정에서 Sermon을 허용하세요.
  • 공유기가 컴퓨터에 새 IP를 주면 OBS와 연결된 Sermon이 1분 안에 OBS의 주소를 스스로 고칩니다. 연결이 없으면 Sermon에서 주소를 다시 복사해 소스에 붙여 넣으세요.
  • 주소가 절대 바뀌지 않게 하려면 공유기 설정에서 Sermon 컴퓨터에 고정 IP를 예약하세요(보통 DHCP 예약이라고 합니다).
주소가 더 이상 작동하지 않습니다
  • 공유기가 컴퓨터에 새 IP를 주었습니다. Sermon을 OBS에 연결하면 그다음부터 Sermon이 주소를 스스로 고칩니다. 그 전까지는 주소를 다시 복사하세요.
  • 주소가 :8091 이상으로 끝나면 8090 포트가 사용 중이었습니다. 예를 들어 Sermon이 두 개 열려 있었을 수 있습니다. 모두 닫고 Sermon을 다시 실행하세요.
슬라이드가 작거나 잘립니다

소스 속성에서 너비를 1920, 높이를 1080으로 설정하세요. 그다음 소스를 오른쪽 클릭 → 변환 → 화면에 맞추기.

Sermon이 OBS에 연결되지 않습니다
  • OBS에서 WebSocket 서버 사용이 체크되어 있고 Sermon의 비밀번호가 정확히 같은지 확인하세요.
  • 두 프로그램 모두 포트가 4455여야 합니다.
  • OBS가 다른 컴퓨터에 있다면 서버 주소는 localhost가 아니라 연결 정보의 서버 IP여야 합니다. 그 컴퓨터의 방화벽에서 OBS를 허용하세요.

아직 Sermon이 없나요?

무료, 인터넷 없이 작동, 가입 필요 없음.
