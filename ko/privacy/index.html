Sermon

개인정보 처리방침

Sermon은 Sermon 팀이 만든 교회용 무료 프레젠테이션 앱입니다. 이 페이지는 Sermon 앱과 이 웹사이트를 사용할 때 사용자의 정보가 어떻게 되는지 설명합니다.

최종 업데이트: 2026년 10월 11일

이 페이지 내용

요약 컴퓨터에 저장되는 데이터 앱이 인터넷에 연결되는 경우 로컬 네트워크에서 이 웹사이트 저희에게 이메일을 보내는 경우 사용자의 권리 변경 사항 및 연락처

요약

  • Sermon에는 계정, 광고, 분석, 추적이 없습니다.
  • 찬양, 성경 본문, 광고, 사진, 동영상, 설정은 모두 사용자의 컴퓨터에 남습니다.
  • 저희는 개인정보를 수집하거나 판매하거나 공유하지 않습니다.
  • 앱은 아래에 설명한 기능을 위해서만, 그리고 그곳에 적힌 서비스에만 인터넷으로 연결합니다.

컴퓨터에 저장되는 데이터

라이브러리, 재생목록, 타이머, 설정은 컴퓨터의 Sermon 데이터 폴더에 저장됩니다. 입력한 경우 OBS 서버 주소와 비밀번호도 여기에 포함됩니다. 이 중 어떤 것도 저희에게 전송되지 않습니다.

백업은 설정 → 백업 → 백업 폴더에서 선택한 폴더에 저장됩니다. 그 폴더가 USB 드라이브나 Google Drive, OneDrive 같은 클라우드 폴더라면 백업은 해당 드라이브나 서비스가 관리합니다.

Sermon을 제거해도 데이터 폴더는 남아 있으므로 다시 설치하면 라이브러리가 그대로 돌아옵니다. 언제든지 이 폴더를 직접 삭제할 수 있습니다.

앱이 인터넷에 연결되는 경우

업데이트. Sermon은 시작할 때마다 GitHub에 새 버전이 있는지 확인하고, 업데이트를 선택하면 GitHub에서 설치 프로그램을 내려받습니다. GitHub 개인정보 보호정책에 설명된 대로 GitHub는 사용자의 IP 주소를 볼 수 있습니다. 확인 기능은 설정 → 일반 → 업데이트 → 자동으로 업데이트 확인에서 끌 수 있습니다.

인터넷의 사진과 동영상. 인터넷에서 찾기를 사용하면 검색어가 Pexels로 전송되고, 선택한 사진이나 동영상은 Pexels에서 내려받습니다. Pexels 개인정보 처리방침을 참고하세요.

YouTube. YouTube 링크를 추가하면 Sermon은 무료 도구 yt-dlp를 GitHub에서 한 번 내려받고 동영상을 YouTube에서 재생합니다. OBS에서는 동영상이 youtube.com에서 삽입됩니다. YouTube는 Google 서비스입니다: Google 개인정보처리방침을 참고하세요.

그 밖에는 아무것도 전송되지 않습니다. 사용 통계, 오류 보고서, 개인정보 모두 보내지 않습니다.

로컬 네트워크에서

OBS용 슬라이드. Sermon은 현재 슬라이드를 네트워크 안에서 웹 페이지(포트 8090)로 보여 주어 OBS나 다른 컴퓨터의 브라우저가 표시할 수 있게 합니다. 같은 네트워크에 있는 사람은 누구나 이 페이지를 열 수 있습니다. 이 페이지에는 프로젝터에 나오는 내용만 표시됩니다. 처음 실행할 때 Windows가 이를 허용할지 물을 수 있습니다.

OBS 연동은 OBS 연동 사용을 켰을 때만 동작합니다. 그러면 Sermon은 입력한 비밀번호로 OBS에 연결해 장면을 전환하고 브라우저 소스의 주소를 최신 상태로 유지합니다. 저장된 주소로 OBS에 연결할 수 없으면, Sermon은 OBS 포트에 응답하는 컴퓨터를 확인해 로컬 네트워크에서 OBS를 찾습니다. 이 모든 과정은 사용자의 네트워크 안에서만 이루어집니다.

이 웹사이트

이 사이트는 GitHub Pages에서 호스팅됩니다. GitHub 개인정보 보호정책에 설명된 대로 GitHub는 보안을 위해 방문자의 IP 주소를 기록할 수 있습니다.

쿠키, 분석, 광고는 없습니다. 글꼴은 Google이 아닌 이 사이트에서 불러옵니다. 브라우저는 선택한 언어와 밝은/어두운 테마를 기억합니다(로컬 저장소). 이 데이터는 브라우저 밖으로 나가지 않습니다.

다운로드 버튼은 GitHub에 최신 릴리스를 요청하므로 브라우저가 api.github.com에 연결합니다.

저희에게 이메일을 보내는 경우

sermon.support@gmail.com으로 메일을 보내시면 저희는 이메일 주소와 메시지를 받아 답장하는 데만 사용합니다. 메일함은 Gmail이 운영합니다(Google 개인정보처리방침). 요청하시면 보내신 메일을 삭제해 드립니다.

사용자의 권리

저희는 Sermon 사용자의 개인정보를 보관하지 않으므로 보여 드리거나 수정하거나 삭제할 것이 없습니다. 보내신 이메일에 관해서는 sermon.support@gmail.com으로 연락해 주세요. EU 또는 영국에 거주하신다면 GDPR에 따른 권리도 있으며, 여기에는 개인정보 보호 기관에 이의를 제기할 권리가 포함됩니다.

Sermon은 어린이를 대상으로 하지 않으며 누구의 데이터도 알면서 수집하지 않습니다.
