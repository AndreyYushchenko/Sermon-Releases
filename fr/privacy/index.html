Politique de confidentialité

Sermon est une application de présentation gratuite pour les églises, faite par l’équipe Sermon. Cette page explique ce que deviennent vos informations quand vous utilisez l’application Sermon et ce site.

Dernière mise à jour : 12 octobre 2026

En bref

  • Sermon n’a ni compte, ni publicité, ni statistiques de suivi.
  • Vos chants, textes bibliques, annonces, photos, vidéos et paramètres restent sur votre ordinateur.
  • Nous ne collectons, ne vendons et ne partageons aucune donnée personnelle.
  • L’application ne va sur Internet que pour les fonctions décrites plus bas, et seulement vers les services cités.

Les données sur votre ordinateur

Votre bibliothèque, vos playlists, minuteurs et paramètres sont enregistrés dans le dossier de données de Sermon sur votre ordinateur, y compris l’adresse et le mot de passe du serveur OBS si vous les saisissez. Rien de tout cela ne nous est envoyé.

Les sauvegardes vont dans le dossier choisi dans Paramètres → Données et sauvegardes → Dossier de sauvegarde. Si ce dossier est une clé USB ou un dossier cloud comme Google Drive ou OneDrive, les copies sont gérées par ce support ou ce service.

Si vous désinstallez Sermon, le dossier de données reste en place : après une réinstallation, votre bibliothèque est toujours là. Vous pouvez supprimer ce dossier vous-même à tout moment.

Quand l’application va sur Internet

Mises à jour. À chaque démarrage, Sermon demande à GitHub s’il existe une version plus récente, et télécharge l’installateur depuis GitHub si vous choisissez de mettre à jour. GitHub voit votre adresse IP, comme l’explique la déclaration de confidentialité de GitHub. Vous pouvez couper cette vérification dans Paramètres → Général → Mises à jour → Rechercher les mises à jour automatiquement.

Photos et vidéos d’Internet. Quand vous utilisez Rechercher en ligne, les mots recherchés sont envoyés à Pexels, et les images ou vidéos choisies sont téléchargées depuis Pexels. Voir la politique de confidentialité de Pexels.

YouTube. Quand vous ajoutez un lien YouTube, Sermon télécharge une fois l’outil gratuit yt-dlp depuis GitHub et lit la vidéo depuis YouTube. Dans OBS, la vidéo est intégrée depuis youtube.com. YouTube est un service de Google : voir les règles de confidentialité de Google.

Module de présentation. Si aucun logiciel de votre ordinateur n’ouvre un fichier PowerPoint ou OpenDocument, Sermon propose de télécharger une fois LibreOffice depuis le site de LibreOffice (The Document Foundation) dans son propre dossier. Vos présentations sont converties sur votre ordinateur et ne sont envoyées nulle part. Voir la politique de confidentialité de The Document Foundation.

Rien d’autre n’est envoyé : pas de statistiques d’utilisation, pas de rapports de plantage, pas de données personnelles.

Sur votre réseau local

Diapositives pour OBS. Sermon affiche la diapositive en cours comme une page web sur votre réseau (port 8090), pour qu’OBS ou un navigateur sur un autre ordinateur puisse la montrer. Toute personne sur le même réseau peut ouvrir cette page. Elle montre seulement ce qui est sur le projecteur. Au premier démarrage de Sermon, Windows peut demander s’il faut l’autoriser.

L’intégration OBS ne fonctionne que si vous activez Activer l’intégration OBS. Sermon se connecte alors à OBS avec le mot de passe saisi, change de scène et tient à jour l’adresse dans vos sources Navigateur. Si OBS ne répond pas à l’adresse enregistrée, Sermon le cherche sur votre réseau local en regardant quels ordinateurs répondent sur le port d’OBS. Tout cela reste à l’intérieur de votre réseau.

Ce site

Le site est hébergé sur GitHub Pages. GitHub peut enregistrer l’adresse IP des visiteurs pour des raisons de sécurité, comme l’explique la déclaration de confidentialité de GitHub.

Il n’y a ni cookies, ni statistiques, ni publicité. Les polices sont servies par ce site, pas par Google. Votre navigateur retient la langue et le thème clair ou sombre que vous choisissez (stockage local) ; cela ne quitte jamais votre navigateur.

Les boutons de téléchargement demandent à GitHub la dernière version, donc votre navigateur contacte api.github.com.

Si vous nous écrivez

Quand vous écrivez à sermon.support@gmail.com, nous recevons votre adresse et votre message, et nous nous en servons seulement pour vous répondre. La boîte mail est gérée par Gmail (règles de confidentialité de Google). Demandez-le-nous et nous supprimerons vos e-mails.

Vos droits

Nous ne gardons aucune donnée personnelle sur les utilisateurs de Sermon : il n’y a donc rien à montrer, corriger ou supprimer. Pour les e-mails que vous nous avez envoyés, écrivez à sermon.support@gmail.com. Si vous vivez dans l’UE ou au Royaume-Uni, vous avez aussi les droits prévus par le RGPD, dont celui de porter plainte auprès de votre autorité de protection des données (en France, la CNIL).

Sermon ne s’adresse pas aux enfants et ne collecte sciemment les données de personne.

Modifications et contact

Si cette politique change, nous mettons à jour cette page et sa date. Les changements importants sont aussi signalés dans les notes de version.

L’équipe Sermon, sermon.support@gmail.com
