Les diapositives de Sermon dans OBS

Mettez les chants, les versets et les annonces du projecteur dans votre direct. Sermon donne à OBS une page web avec la diapositive en cours : ajoutez-la une fois comme source Navigateur, et ensuite elle suit le projecteur.

  • Environ 5 minutes
  • OBS Studio 28 ou plus récent
  • Cet ordinateur ou un autre sur votre réseau

Avant de commencer

  • Sermon 0.3.0 ou plus récent. Connecté à OBS, il tient lui-même à jour l’adresse dans OBS, même quand le routeur donne une nouvelle adresse IP à un ordinateur.
  • OBS Studio installé, sur cet ordinateur ou sur un autre ordinateur du même réseau.
  • Sermon ouvert pendant le culte : OBS y prend les diapositives.

Connexion en 5 étapes

1

Étape 1

Copiez l’adresse dans Sermon

Dans le panneau de droite, à côté de OBS, cliquez sur Adresse 1. Le lien est copié dans le presse-papiers. Il ressemble à http://192.168.1.25:8090/display.

Le même lien se trouve dans Paramètres → OBS et diffusion → Adresse pour la source Navigateur. Il contient l’adresse IP de cet ordinateur. Si OBS tourne sur un autre ordinateur, connectez aussi Sermon à OBS : quand le routeur change l’adresse IP d’un ordinateur, Sermon corrige alors l’adresse dans OBS tout seul, et vous n’avez plus jamais à la coller.

2

Étape 2

Ajoutez une source dans OBS

Ouvrez OBS Studio et sélectionnez la scène où doivent apparaître les diapositives, par exemple celle de votre caméra. Sous Sources, cliquez sur + 1.

3

Étape 3

Choisissez « Navigateur »

Dans la fenêtre d’ajout de source, choisissez Navigateur 1, puis créez une nouvelle source 2.

4

Étape 4

Collez l’adresse et réglez la taille

URL 1 : videz le champ et collez l’adresse (Ctrl+V).
Largeur 2 : 1920, Hauteur 3 : 1080.

Laissez le reste tel quel et cliquez sur OK 4.

L’aperçu en haut de cette fenêtre ne se met à jour qu’après OK. Quand vous rouvrirez les propriétés plus tard, vous y verrez la diapositive, comme sur l’image.

5

Étape 5

Vérifiez le résultat

La diapositive en cours apparaît maintenant dans OBS et change avec le projecteur. OBS garde la source en mémoire : vous ne le faites qu’une fois.

Si la diapositive ne remplit pas l’image, faites un clic droit sur la source et choisissez Transformer → Ajuster à l’écran (Ctrl+F).

Astuce. Pour laisser voir la caméra quand rien n’est à l’écran, choisissez dans Sermon Paramètres → Écran et affichage → Entre les cultes → Rien : OBS reçoit alors une page transparente. Pour cacher les diapositives seulement dans le direct, cliquez sur Masquer à côté d’OBS dans Sermon : le projecteur continue d’afficher.

Connecter Sermon à OBS

Conseillé quand OBS tourne sur un autre ordinateur. Une fois connecté, Sermon met lui-même à jour l’adresse de la source Navigateur quand le routeur donne une nouvelle adresse IP à un ordinateur, et retrouve OBS sur le réseau si l’adresse d’OBS a changé. Il peut aussi basculer OBS sur une scène choisie quand quelque chose passe à l’écran, et revenir quand vous le masquez. Cela passe par le serveur WebSocket intégré à OBS.

A

Ouvrez les réglages WebSocket

Dans OBS, ouvrez Outils 1 → Paramètres du serveur WebSocket 2.

B

Activez le serveur

Cochez Activer le serveur WebSocket 1. Saisissez votre propre mot de passe dans Mot de passe du serveur 2 ou gardez celui qui est proposé. Cliquez sur OK 3.

C

Trouvez l’adresse du serveur et le mot de passe

Rouvrez Outils → Paramètres du serveur WebSocket et cliquez sur Afficher les informations de connexion. Cette fenêtre contient tout ce qu’il faut à Sermon : l’IP du serveur 1, c’est-à-dire l’adresse de l’ordinateur où tourne OBS, le port du serveur 2 et le mot de passe du serveur 3. Chacun a un bouton Copier.

Si OBS et Sermon tournent sur le même ordinateur, Sermon peut garder l’adresse localhost. L’IP du serveur sert quand OBS est sur un autre ordinateur.

D

Connectez Sermon

Dans Sermon, ouvrez Paramètres → OBS et diffusion et activez Activer l’intégration OBS 1.

Adresse du serveur 2 : collez l’IP du serveur de l’étape précédente, ou laissez localhost si OBS est sur cet ordinateur. Port : 4455. Mot de passe 3 : collez le mot de passe du serveur.

Cliquez sur Tester la connexion 4 : vous devez voir Connecté. Pour changer de scène, choisissez-en une dans Scène de présentation. Cliquez sur Enregistrer.

Si quelque chose ne marche pas

OBS affiche une image vide ou blanche
  • Vérifiez que Sermon est ouvert et qu’à côté d’OBS, dans son panneau de droite, l’état indique En cours.
  • Copiez à nouveau l’adresse avec le bouton Adresse et collez-la dans le champ URL de la source.
  • Cliquez sur Actualiser sous l’aperçu d’OBS.
OBS tourne sur un autre ordinateur
  • Les deux ordinateurs doivent être sur le même réseau (même routeur ou même Wi-Fi).
  • Au premier démarrage de Sermon, Windows peut demander s’il peut utiliser le réseau. Cliquez sur Autoriser. Si vous avez fermé cette fenêtre, autorisez Sermon dans les réglages du pare-feu Windows.
  • Quand le routeur donne une nouvelle adresse IP à un ordinateur, Sermon connecté à OBS corrige l’adresse dans OBS tout seul en moins d’une minute. Sans connexion, copiez à nouveau l’adresse dans Sermon et collez-la dans la source.
  • Pour une adresse qui ne change jamais, réservez une adresse IP fixe pour l’ordinateur de Sermon dans les réglages du routeur (souvent appelé réservation DHCP).
L’adresse ne fonctionne plus
  • Le routeur a donné une nouvelle adresse IP à l’ordinateur. Connectez Sermon à OBS : ensuite Sermon corrige l’adresse tout seul. En attendant, copiez à nouveau l’adresse.
  • Si l’adresse finit par :8091 ou plus, le port 8090 était occupé, par exemple par une deuxième copie de Sermon ouverte. Fermez toutes les copies et relancez Sermon.
La diapositive est petite ou coupée

Dans les propriétés de la source, mettez Largeur à 1920 et Hauteur à 1080. Puis clic droit sur la source → Transformer → Ajuster à l’écran.

Sermon ne se connecte pas à OBS
  • Vérifiez que Activer le serveur WebSocket est coché dans OBS et que le mot de passe dans Sermon est exactement le même.
  • Le port doit être 4455 dans les deux logiciels.
  • Si OBS est sur un autre ordinateur, l’adresse du serveur doit être l’IP du serveur indiquée dans Afficher les informations de connexion, pas localhost. Autorisez OBS dans le pare-feu de cet ordinateur.
