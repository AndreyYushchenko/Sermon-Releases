Sermon: бесплатная программа для показа в церквях, которую делает команда Sermon. Эта страница объясняет, что происходит с вашей информацией, когда вы пользуетесь программой Sermon и этим сайтом.

Коротко

  • В Sermon нет учётных записей, рекламы, аналитики и слежки.
  • Ваши песни, тексты Библии, объявления, фото, видео и настройки остаются на вашем компьютере.
  • Мы не собираем, не продаём и не передаём персональные данные.
  • Программа выходит в интернет только для функций, описанных ниже, и только к названным там сервисам.

Данные на вашем компьютере

Ваша библиотека, плейлисты, таймеры и настройки хранятся в папке данных Sermon на вашем компьютере. В том числе адрес и пароль сервера OBS, если вы их вводите. Ничего из этого нам не отправляется.

Резервные копии сохраняются в папку, которую вы выбираете в Настройки → Данные и резервные копии → Папка для резервных копий. Если это флешка или облачная папка, например Google Drive или OneDrive, копии обрабатывает этот диск или сервис.

После удаления Sermon папка данных остаётся, поэтому после повторной установки библиотека сохранится. Вы можете в любое время удалить эту папку сами.

Когда программа выходит в интернет

Обновления. При каждом запуске Sermon спрашивает у GitHub, есть ли новая версия, и скачивает установщик с GitHub, когда вы решаете обновиться. GitHub видит ваш IP-адрес, как описано в Заявлении GitHub о конфиденциальности. Проверку можно выключить в Настройки → Общие → Обновления → Автоматически проверять обновления.

Фото и видео из интернета. Когда вы пользуетесь Найти в интернете, слова поиска отправляются в Pexels, а выбранные фото или видео скачиваются с Pexels. См. Политику конфиденциальности Pexels.

YouTube. Когда вы добавляете ссылку на YouTube, Sermon один раз скачивает бесплатную утилиту yt-dlp с GitHub и воспроизводит видео с YouTube. В OBS видео встраивается с youtube.com. YouTube, сервис Google: см. Политику конфиденциальности Google.

Модуль презентаций. Если на компьютере нет программы, которая открывает файл PowerPoint или OpenDocument, Sermon предлагает один раз скачать LibreOffice с сайта LibreOffice (The Document Foundation) в свою папку. Презентации преобразуются на вашем компьютере и никуда не отправляются. См. Политику конфиденциальности The Document Foundation.

Больше ничего не отправляется: ни статистики использования, ни отчётов о сбоях, ни персональных данных.

В вашей локальной сети

Слайды для OBS. Sermon показывает текущий слайд как веб-страницу в вашей сети (порт 8090), чтобы OBS или браузер на другом компьютере мог его показать. Эту страницу может открыть любой в той же сети. На ней только то, что сейчас на проекторе. При первом запуске Windows может спросить, разрешить ли это.

Интеграция с OBS работает, только когда вы включаете Включить интеграцию с OBS. Тогда Sermon подключается к OBS с введённым вами паролем, переключает сцены и обновляет адрес в источниках «Браузер». Если OBS недоступен по сохранённому адресу, Sermon ищет его в вашей локальной сети, проверяя, какие компьютеры отвечают на порту OBS. Всё это не выходит за пределы вашей сети.

Этот сайт

Сайт размещён на GitHub Pages. GitHub может записывать IP-адреса посетителей для безопасности, как описано в Заявлении GitHub о конфиденциальности.

Здесь нет cookies, аналитики и рекламы. Шрифты загружаются с этого сайта, а не с Google. Ваш браузер запоминает выбранный язык и светлую или тёмную тему (локальное хранилище); эти данные не покидают ваш браузер.

Кнопки скачивания запрашивают у GitHub новейший выпуск, поэтому ваш браузер обращается к api.github.com.

Если вы нам пишете

Когда вы пишете на sermon.support@gmail.com, мы получаем ваш адрес и сообщение и используем их только для ответа. Почтой управляет Gmail (Политика конфиденциальности Google). Попросите, и мы удалим ваши письма.

Ваши права

Мы не храним персональных данных пользователей Sermon, поэтому нам нечего показать, исправить или удалить. По поводу писем, которые вы нам отправили, пишите на sermon.support@gmail.com. Если вы живёте в ЕС или Великобритании, у вас также есть права по GDPR, в том числе право подать жалобу в орган по защите данных.

Sermon не предназначен для детей и сознательно ничьих данных не собирает.
